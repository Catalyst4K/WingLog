# Bundled airline logo overrides

`<IATA>.png` here is shown instead of the Kiwi image service's logo for that code
(see `AirlineLogo.tsx`). Use it where the service serves a pre-rebrand logo, e.g. `KA.png`
for Cathay Dragon (the service has the old Dragonair one). Square, 64px or larger; only
add a logo whose licence allows redistribution, and note its source below.
